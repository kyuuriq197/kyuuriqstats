# kyuuriqstats

A simple system information fetcher written in Rust.

## Features

- OS
- Window Manager
- Shell
- Uptime

## Modules

- Weather
  
## Start 

Add config.fish kyuuriqstats to the end

## Requirements

- Linux
- Rust
- pacman (for package count)
- niri (for display information)
- nvidia-smi (for NVIDIA GPU detection)

## Build

cargo build --release

## Run

cargo run --release
