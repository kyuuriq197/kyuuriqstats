# kyuuriqstats

A simple system information fetcher written in Rust.

## Features

- OS
- Kernel
- CPU
- RAM
- GPU
- Display
- Window manager
- Shell
- Terminal
- Packages
- Uptime
- Disks

## Requirements

- Linux
- Rust
- pacman (for package count)
- niri (for display information)
- nvidia-smi (for NVIDIA GPU detection)

## Build

cargo build --release

## Run

cargo run --release
